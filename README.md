# QuantStone Backtest

事件驱动型量化回测系统。

## 项目定位

`quantstone-backtest` 负责策略的历史模拟运行，与数据基础设施项目 `quantstone-data` 配合使用。

## 规划范围

- 模拟时钟与事件调度
- 策略生命周期与回调接口
- 历史行情访问与数据适配
- 订单管理与模拟撮合
- 资金、持仓与交易成本核算
- 回测绩效分析与运行日志

## 当前状态

项目初始化阶段，具体架构与接口待设计。
