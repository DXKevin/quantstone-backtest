# QuantStone Backtest

策略研究首页支持整行点击进入独立策略页 `/strategies/{id}`，详情页可直接访问、刷新，提供策略代码、回测结果及历史记录。列表、新建策略和任务记录均区分品种与市场；目前只支持股票 / A股。

数据源是服务端配置，不在回测表单中选择。服务默认通过 QuantStone Data SDK 读取真实行情，SDK 服务地址由 `QUANTSTONE_API_URL` 设置。合成测试行情只能用 `QUANTSTONE_DATA_SOURCE=demo` 显式启用；它采用无长期漂移、按日期固定的有界价格，仅用于验证系统流程，单次最多运行 90 天，不能用于评价策略表现。所有新任务遵循服务端配置；旧任务快照不变。

Python 回测核心与 TypeScript Web 前端组成的 A 股事件驱动、模拟账户级回测工作台。支持日线和分钟线，在本地网页管理策略、编写代码、配置回测并查看结果。项目仍处于首版开发阶段。

## 快速开始（Linux）

```bash
cd /home/quantadmin/project/quantstone-backtest
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
# 使用真实行情时安装同级数据项目的 SDK：
.venv/bin/python -m pip install -e ../quantstone-data/sdk/python
.venv/bin/quantstone-backtest --runs-dir var/runs
```

服务默认监听 `0.0.0.0:8010`。同一局域网的电脑打开
`http://服务器局域网IP:8010`；服务器本机仍可访问
<http://127.0.0.1:8010>。可先用短区间合成测试行情运行默认策略，合成行情与真实市场收益无关。

```bash
hostname -I
```

工作台允许回环地址、RFC 私有局域网 IP、本机主机名和链路本地地址，无需依赖 DNS。如果使用自定义局域网域名，显式加入浏览器使用的域名：

```bash
.venv/bin/quantstone-backtest --allowed-host backtest.lan
```

只应在可信局域网开放 8010 端口，因为登录工作台的人可以运行 Python 策略代码。不要把该端口映射到公网。若系统启用了防火墙，还需仅向可信局域网网段放行 TCP 8010。

数据服务默认地址为 `http://127.0.0.1:8000/api/v1`，可通过环境变量 `QUANTSTONE_API_URL` 修改。策略档案保存在 `var/strategies/`，运行结果、参数和当次策略快照保存在 `var/runs/`，均不进入 Git。程序不会修改数据服务或自动补采数据。

网页只用于可信用户自己的策略代码。策略可以导入 Python 模块并访问进程权限范围内的文件和网络；工作进程隔离用于取消、超时与故障隔离，不是恶意代码沙箱。局域网版没有登录认证；生产化多人服务需要单独设计认证与执行隔离。

## 已实现

- 日线/分钟线事件回放，盘前、行情和盘后基础回调；订单与成交回调作为高级可选接口。
- 下一根 K 线开盘价撮合，市价意图及限价委托，撤单、拒绝、结束到期与回报。
- 可用/冻结资金、持仓/可卖/冻结数量、买入后次交易日可卖的模拟规则。
- 可配置佣金、最低佣金、卖出税费与过户费；Decimal 记账、盈亏和每日净值。
- 已完成行情窗口，分钟策略可查询已完成日线；策略查询或下单时后台自动加载行情，无需配置股票池或手动订阅。
- Python SDK 数据读取、字段/单位转换、交易日历、涨跌停价与复权因子驱动的公司行动记账。
- Web 策略研究入口、可折叠及改名的策略目录、策略搜索与筛选、策略档案、TypeScript + CodeMirror 代码编辑器、独立进程运行、取消、按策略归属的历史及结果导出。回测运行时按交易日增量发布净值并实时更新收益曲线；完成后结果工作区展示累计与年化收益、最大回撤、Sharpe、年化波动率、上涨日占比、累计收益曲线、每日收益、成交时间轴、账户摘要及交易明细。编辑器支持行号、Python 高亮、搜索、缩进、折叠、接口补全以及保存/运行快捷键。费用通过策略 init 中的 ctx.set_fees 设置。
- 单 API 进程最多同时运行两个回测，单次默认超时 600 秒；历史结果持久化。

## 当前模型边界

- 支持沪深主板与创业板代码；科创板、北交所、其他资产暂不支持。买入按 100 股整数倍，零股卖出只允许一次卖完可卖持仓。
- 订单默认持续有效至成交、撤单或回测结束。未满足限价或不利涨跌停价约束时保留订单。固定股数委托在实际开盘资金不足时拒绝；`context.order_all` 会按实际开盘价、费用和整手规则动态计算最大买入量，或卖出全部可卖持仓（包括公司行动产生的小数股）。
- 当前每笔委托一次全额成交；未实现部分成交、逐笔队列、成交量参与率、滑点和盘中限价触达。接口与数据模型后续可扩展。
- 撮合不读取当前 K 线尚未形成的高低收或整根成交量。无对应行情时不撮合；分钟缺口不自动插值，不保证所有缺口都能区分停牌和数据缺失。
- 固定费率是可修改的模拟参数，不代表任意历史时点或全部证券的完整收费标准。
- 真实行情保持未复权成交价。复权因子变化在除权日盘前按“分红再投资”处理：持股数量乘以新旧因子比例，允许 6 位小数股，总持仓成本不变。普通买入仍遵守 A 股整手规则。除权前未成交委托会自动取消，避免旧价格跨越公司行动。
- 分钟数据存在契约和实测标签冲突：默认按结束标签解读 `09:31…11:30、13:01…15:00`，跳过 `09:30` 记录。网页可改为严格开始标签模式；详情见 [数据契约](docs/data-contracts.md)。
- 暂无全市场选股/任意基本面查询、策略依赖安装界面、历史数据版本锁定、实盘或公开部署。行情按需加载仍以每只股票完整回测区间为单位，尚未实现分段缓存。
- 单任务最多 20 只股票，分钟数据最多 500000 根；首版定位为功能和正确性基线，尚未做全市场性能优化。

## 测试

```bash
.venv/bin/python -m pytest -q
npm ci
npm run typecheck
npm run build:web
```

运行服务不需要 Node.js，仓库已提交构建后的 `static/app.js` 和 `static/editor.js`。修改 `web/app.ts` 或 `web/editor.ts` 后需要执行类型检查并重新构建。

可选浏览器验证（先启动本地服务）：

```bash
.venv/bin/python -m pip install playwright
.venv/bin/python -m playwright install chromium
.venv/bin/python scripts/browser_smoke.py
```

核心与 API 测试使用合成数据，不要求数据服务运行。API 测试会实际启动独立工作进程，检查结果持久化、异常、取消、超时与请求校验。
